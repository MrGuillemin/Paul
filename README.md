# Révision Quest

Petit site pédagogique statique pour GitHub Pages.

## Structure

- `index.html` : accueil général
- `style.css` : style commun
- `app.js` : fonctions communes
- `anglais/` : chapitres d'anglais
- `francais/` : chapitres de français
- `maths/` : chapitres de maths

## Ajouter un nouveau chapitre

1. Ajouter le nouveau fichier `.html` dans le bon dossier.
2. Ajouter une carte/lien vers ce fichier dans le `index.html` de la matière.
3. Envoyer uniquement ces nouveaux fichiers/modifications sur GitHub.

Les anciens chapitres n'ont pas besoin d'être réécrits.
